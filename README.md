# 🛍️ Cloud-Native Enterprise E-Commerce Platform - Frontend

A responsive, mobile-first client application built with modern web technologies to deliver a seamless shopping, authentication, and checkout experience.

---

## ✨ Key Features

- 📱 **Mobile-First Responsive UI** — Designed with a fluid layout and styled efficiently using Tailwind CSS.
- 🛒 **Dynamic Cart & State Management** — Real-time cart management with local state persistence using Redux Toolkit.
- 🔐 **Dual-Login Authentication** — Supports standard JWT-based email/password login and OAuth 2.0 Google Sign-In.
- ⚡ **Optimized Performance** — Client-side search filtering and low-latency rendering powered by state caching and TypeScript interfaces.

---

## 🛠 Tech Stack

- **Framework:** React
- **State Management:** Redux Toolkit
- **Language:** TypeScript
- **Styling:** Tailwind CSS
